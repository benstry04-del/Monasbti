# تجربة هَبّ السعد الحركية

## التشغيل والعرض

من جذر المشروع: `npm start` ثم افتح `http://localhost:5173/`. النسخة المبنية: `npm run build` ثم `npm run preview` (المنفذ الافتراضي 4173). تسجيل Service Worker والتخزين دون اتصال مفعّلان في النسخة المبنية على localhost أو HTTPS فقط، ولا يعملان في dev لتجنب تخزين ملفات HMR.

`/demo/motion` مختبر العرض: أول زيارة، Splash عائد، إعادة مشاهدة، رفع الإصدار، حالات الوسائط والشبكة، تعطيل WebGL، الحركة المخفّضة، تأخر الجاهزية، سياقات التحميل، مهام بتقدم حقيقي وتنزيل سجل الأحداث. لا تعيد أدوات الحركة ضبط بيانات الحجز. أدوات المختبر ليست صفحة عميل ولا يلزم المرور بها للاستخدام.

## ما يظهر للمستخدم

- أول دخول: الفيلم الأصلي 20.01 ثانية، صامت افتراضيًا، مع أزرار صوت وإيقاف/استئناف؛ التخطي بعد 2.8 ثانية من التشغيل. بعد الاكتمال أو التخطي يُحفظ الإصدار والتاريخ والنتيجة، ثم Logo Morph إلى الصفحة المطلوبة.
- الدخول التالي: Splash من نفس الشعار والمواد، يبدأ تفكيك القطع ثم جمعها. إن كان التطبيق جاهزًا يختصر التسلسل بعد الحد الأدنى 1.45 ثانية، ثم انتقال 420ms. إن تأخرت الجاهزية تستمر الشاشة نفسها كتحميل دون طبقة ثانية. الصفحة الأصلية مركبة خلفها وتحتفظ بالمسار.
- الرئيسية: بطاقة الفيلم مباشرة بعد Hero. الملصق وحده يُحمّل؛ لا فيديو تلقائيًا عند التمرير. المشغل اليدوي يغلق بالزر أو Escape أو سحب لأسفل باللمس، ويعيد التركيز وموضع التمرير.
- جميع أوامر Mock API المهمة تمر عبر وحدة التحميل: أقل من350ms لا مؤشر، ثم نقاط ذهبية في العنصر، ثم لوحة سياقية عند1.2s، ثم طبقة كاملة عند3s. النسبة لا تظهر إلا عند تزويد تقدم معروف. نجاح الدفع مرتبط بـPAID فقط، والـPENDING/3DS لا يطلقان الاحتفال.
- الحركة المخفّضة: شعار ثابت/تلاشي قصير، دون WebGL أو مدارات. الفيلم ملصق مع تشغيل اختياري، مع إمكانية المتابعة. فشل الوسائط لا يحجب الوصول إلى التطبيق. فشل WebGL أو تحميل وحدته يتحول إلى CSS 2.5D.

## الملفات والعقود

| الملف | الوظيفة |
|---|---|
| `src/experience/ExperienceOrchestrator.tsx` | اختيار تجربة Boot وجاهزية التطبيق وملكية الطبقات والمشغل اليدوي |
| `src/experience/core.mjs` | آلة الحالات، القيم الزمنية، السياقات، قرارات المصدر البديل، التخزين القابل للاختبار |
| `src/services/experienceStateService.ts` | حفظ الإصدار والصوت والإعدادات دون ربط المكونات بـlocalStorage |
| `src/services/mediaPreloadService.ts` | اختيار MP4/WebM ونسخة الهاتف، تدفئة الصور فقط، اللمسة الصوتية الاختيارية |
| `src/experience/loading-controller.ts` | start / update / finish / run مع تنظيف المؤقتات عند النجاح والفشل |
| `src/components/brand-motion` | المشغل والبطاقة والشعار وThree stage ومكونات التحميل |
| `src/experience/motion.css` | الهوية والاستجابة والحركة والحالات المخفّضة |
| `public/sw.js` | Shell cache، ملفات الواجهة والخطوط والصور؛ لا يخزن الفيلم أو طلبات Range |
| `tests/motion.test.mjs` | اختبارات الحالة والعتبات والتخزين والفشل |
| `tests/motion.spec.ts` | سيناريوهات Playwright قابلة للتشغيل مجددًا |

لدمج طلب جديد:

```ts
await loadingExperience.run({ context: 'contract', scope: 'section' }, async () => {
  return await actualRequest();
});
// أو start ثم update(id, completed / total) ثم finish في finally.
```

`markAppReady()` يُستدعى من App بعد التركيب وRAF. عند ربط Backend لاحقًا يُستدعى بعد الحد الأدنى الحقيقي من البيانات الحرجة؛ لا يُستبدل بمؤقت تقدّم مزيف. التأخير في المختبر محاكاة صريحة لهذه الجاهزية.

التفضيلات: `habbIntroSeenVersion`, `habbIntroCompletedAt`, `habbIntroSkipped`, `habbMotionMuted`. عند تعذر التخزين يستمر النظام بذاكرة الجلسة. التخزين في هذا البروتوتايب على الجهاز؛ لا يوجد Backend لمزامنة التفضيل عبر حسابات أو أجهزة. رفع إصدار الإنتاج يتم عبر `INTRO_VERSION` وDEFAULT_DIAGNOSTICS، مع تحديث أسماء الوسائط ونسخة Cache عند تغيير الأصول.

السجل المحلي محدود بـ150 حدثًا، مع حدث Window باسم `habb:experience-event`. لا يُرسل لأي مزود. metadata تشمل فئة الجهاز والشبكة إن وفرها المتصفح، وإصدار المقدمة/مدة الجاهزية بحسب الحدث، دون معلومات العميل أو الدفع.

## الأصول ومصدرها

جرت قراءة جميع عناصر الحزمة: README_FIRST وMASTER_SPEC والـDOCX والصورة الأصلية والفيلم. النص المستخرج للـDOCX في `docs/habb-docx-extracted.txt`. الفيلم الأصلي لم يُعد توليده؛ أُعيد ضغطه فقط مع الحفاظ على جميع المشاهد والصوت والمدة ونسبة الصورة. بياناته وبصمته في `media-manifest.json` والـstoryboard في `source-storyboard.jpg`. المصدر720×1280 عمودي؛ يستخدم العرض `contain` مع بيئة لونية محيطة، دون تمديد أو ادعاء جودة4K.

الشعار الأصلي محفوظ كما هو في `public/brand-motion/logo/habb-logo-reference.png` ونسخة WebP محسّنة دون إعادة رسم. التجميع يستخدم قصاصات CSS من الصورة الأصلية ويحافظ على الشعار النهائي كاملًا.

عناصر المناسبات مولّدة عبر ImageGen كأطلس RGBA واحد: Ribbon، ورد، كرسي، طاولة، شمعة، ثريا، دلة وفنجان، دعوة، ستارة، قوس، خواتم، زخارف ذهبية. الموجز: "12 cohesive miniature luxury Kuwaiti celebration objects, warm ivory champagne gold and deep burgundy, premium realistic materials, consistent soft studio light, transparent background, exact 4 columns by 3 rows, no text, no logo". أُنتجت نسخة WebP1280×960. تستخدم المشاهد Sprites داخل فضاء Three ثلاثي الأبعاد مع Ribbon Mesh حقيقي وإضاءة وجسيمات؛ البديل CSS يحافظ على نفس الأطلس والشعار. هذه استراتيجية خفيفة، وليست مجموعة نماذج glTF لم تُرفق بالحزمة.

ميزانية صور التحميل الأساسية: الشعار59,786 + الأطلس437,556 =497,342 بايت. الملصق37,694 بايت. الفيديو المحمول MP4≈2.63MB، WebM≈2.74MB؛ المكتبيMP4≈5.24MB، WebM≈4.68MB. لا يطلب الفيلم في الدخول العائد. Three محمّل عبر chunk منفصل، DPR≤1.5، حلقته تتوقف خارج الشاشة/عند إخفاء الصفحة، وتنظف موارد GPU عند إلغاء التركيب.

## الاختبارات

`npm test` ثم `npm run build`. لاختبارات المتصفح القابلة للإعادة: `npx playwright install chromium` مرة واحدة ثم `npm run test:e2e`. اختبارات الأعمال تهيئ حالة المشاهدة وحدها لتفصل رحلة الحجز عن السينما؛ اختبارات الحركة مستقلة في `motion.spec.ts`. نتائج الفحص المنفذ فعليًا وحدوده في QA.md.
