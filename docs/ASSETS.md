# أصول الهوية

الصور في `references/` مراجع تصميم فقط، ولم تُستخدم كصور صفحات أو خلفيات تحاكي الواجهات. فُحصت الصور الثماني، واستُخرج كامل نص DOCX وXML الداعمة إلى `docx-extracted.txt`.
